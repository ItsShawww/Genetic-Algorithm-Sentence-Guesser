<H1>Sentence Guesser</H1>

A piece of crappy software written in C that uses Genetic Algo to guess a sentence. It works on the principles of Darwinism Theory to guess the sentence and get closer to it with each generation through constant cycle of reproduction and mutation. Similar to animals each offspring has two parents that shares DNA and then with some random variation an offspring is created which gets more and more closer to the sentence.
